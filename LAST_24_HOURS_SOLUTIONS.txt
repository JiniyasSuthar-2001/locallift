2. ENTERPRISE TEAM COLLABORATION & GRANULAR ACCESS CONTROL (RBAC)
--------------------------------------------------------------------------------
Problem:
- Projects lacked team delegation, permission granularity, and invitation lifecycle 
  handling for multi-client agencies.

Solution Implemented:
- Backend Database Models & Schemas:
  * Created `ProjectMember` and `TeamInvitation` models with granular permission flags:
    `can_audit`, `can_edit_settings`, `can_manage_team`, `can_view_reports`, `can_export`.

    expiry tokens and user linkage.

  * Implemented `/api/v1/team/projects/{project_id}/members` for listing, adding, 
    updating roles, and removing collaborators.
  * Implemented `/api/v1/team/projects/{project_id}/invitations` for sending, 
    accepting, and revoking invitations with automatic role provisioning.
  * Implemented `/api/v1/team/directory` to aggregate all members, active projects, 
    and roles across the user's workspace.
- Frontend UI Components:
  * Built `TeamDirectoryView.tsx`: Global collaborator management, invite modal, 
    and role/permission matrix.
  * Built `ProjectTeamSection.tsx`: In-context team panel within Project Settings 
    and Project Details with live permission toggles.
  * Built `InvitationNotificationModal.tsx`: Real-time banner/modal prompting 
    users when invited to collaborate on new projects.
  * Hardened polling logic so invitation checks run exclusively when the user is 
    authenticated, eliminating unnecessary background network noise.

3. GOOGLE CONNECTIONS & PUBLIC MAPS SHORT-LINK PARSER ENGINE
--------------------------------------------------------------------------------
Problem:
- Users needed to link Google Business Profile (GBP), Google Search Console (GSC), 
  and Google Analytics 4 (GA4) with OAuth or lightweight Public Maps links without 
  mandatory complex Google Cloud console configurations.
- Google Maps short URLs (`maps.app.goo.gl`, `goo.gl/maps`) often failed to parse, 
  losing Place IDs, CID numbers, or coordinates.

Solution Implemented:
- Connections Architecture (`backend/app/services/google/connections_service.py`):
  * Unified status management for GBP, GSC, and GA4 connections per project.
  * Token refresh lifecycle, manual disconnect, and sync status endpoints.
- Public Maps Link Resolver (`backend/app/services/google/public_maps_service.py`):
  * Automated redirect-unfurling engine that follows HTTP 301/302 redirects 
    on short-links (`maps.app.goo.gl`, `goo.gl/maps`).
  * Regex extraction of Place IDs (`ChIJ...`), CID numbers (`0x...:0x...`), 
    coordinates (`@lat,lng`), and business names from canonical URL paths.
- Frontend Connections Hub (`ConnectionsView.tsx` & `GoogleCallbackView.tsx`):
  * One-click OAuth initiation with dynamic callback redirect handling.
  * Instant manual Public Maps link validator with immediate preview of extracted 
    CID, Place ID, and business metadata.
  * Status badges, last-synced timestamps, and direct disconnect actions.
